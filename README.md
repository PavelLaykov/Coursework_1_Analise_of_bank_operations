 ========== Banking operations analysis ==========
# Проект 1. Приложение для анализа банковских операций

## Основная цель программы
### Банк работает со счетами клиентов, постоянно расширяя спектр услуг.
### IT-отдел банка разрабатывает Banking operations analise - это backend, 
### который готовит данные для отображения в widget, 
### в личном кабинете клиента крупного банка.
### Это приложение позволяет выполнять поиск по Excel-файлу для анализа транзакций. 
### Приложение генерирует JSON-данные для веб-страниц, формирует отчеты с записью в файл,
### а также предоставляет другие сервисы по банковским операциям клиента
### (4 последние номера карты, общая сумма расходов, кешбэк, 
### ТОП-5 транзакций по сумме платежа, курсы валюты и акций S&P500). 

## Описание модулей:

1. Excel-файл с транзакциями находится в папке ./data.
2. В пакете src находятся модули со следующими функциями:
- Модуль main позволяет вызвать все функциональности проекта.
- Главная функция для анализа данных реализована в отдельном модуле views. 
- Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, по входящую дату. Валюты и акции для отображения на веб-страницах заданы в отдельном файле пользовательских настроек user_settings.json.
- Вспомогательные функции находятся в файле utils.py
- Сервис для определения выгодных категорий повышенного кэшбэка реализован в модуле services.
- В модуле reports реализована функция формирования отчета трат по категориям. Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).

Для функций отчетов также написан декоратор. Он находится в модуле decorators. Декоратор записывает сформированный в формате DataFrame отчет в файл.
В модуле utils расположены вспомогательные функции для чтения файлов.
В модуле external_api находятся функции для получения данных о валютах и акциях через Open API api.apilayer.com и api.polygon.io
В пакете tests находятся тесты на функции основного функционала.
В файле logging_config реализован логгер, который используется в функциях, выполняющих основной функционал.

Веб-страницы:
Главная
- функция выполняющая приветствие в зависимости от времени суток
- функция, которая выводит по каждой карте:
    последние 4 цифры карты;
    общую сумму расходов;
    кешбэк (1 рубль на каждые 100 рублей)
- функция, которая выводит Топ-5 транзакций по сумме платежа
- функция, которая выводит курс валют в USD и EUR к RUB, происходит обращение к внешнему API
- функция, которая выводит стоимость акций из списка S&P500. Происходит обращение к внешнему API.

Сервисы:
Простой поиск:
 - функция, которая получает строку для поиска и список транзакций.
Выводит список транзакций, в которых есть данная строка

Отчеты:
Траты по категории:
- декоратор для записи отчета в файл
- функция, которая принимает на вход: датафрейм с транзакциями, название категории,
опциональную дату. Если дата не передана, то берется текущая дата. Функция возвращает
траты по заданной категории за последние три месяца (от переданной даты).

### main
    * Этот модуль будет содержать функции для работы с новыми возможностями приложения.
    * В модуле обрабатывается информацию как о картах, так и о счетах, анализирует транзакции клиентов.

## ------------- Установка и использование -------------

### **Требования (Requirements):**

    1. **Python** версии 3.14.3
    2. **Poetry** версия 2.3.2
    3. Смотрите файл `pyproject.toml` для получения информации о версиях зависимостях проекта.

### **Установка:**

## Для использования проекта необходимо:

1. Установить [PyCharm](https://www.jetbrains.com/ru-ru/pycharm/download/?section=windows).
2. Установить интерпретатор [Python](https://www.python.org/downloads/).
3. Установить в PyCharm poetry.
 
    # В PowerShell
[Invoke-WebRequest-Uri](https://install.python-poetry.org)-UseBasicParsing.Content | python -
    Или через curl (если установлен).

    ```
    curl -sSL https://install.python-poetry.org | python -
    ```

    4. **Клонируйте проект** из этого репозитория, используя в PyCharm 
    (в командной строке терминала) команду:

    git clone https://github.com/git@github.com:PavelLaykov/coursework_1.git

    5. **Инициализируйте виртуальное окружение** командой:

    python -m venv <название_окружения>

    *Например:*

    python -m venv venv

    Однако важно убедиться, что у вас корректно настроен путь к Python в системной переменной `PATH`, чтобы команда работала без ошибок. 
    О том, как добавить Python в PATH в Windows 11, смотри 
[здесь](https://ip-calculator.ru/blog/windows-11/how-to-add-python-to-path-on-windows-11-2/).

    1. **Активируйте окружение** с помощью команды:
    *   на macOS и Linux:

    source venv/bin/activate

    *   на Windows:

    venv\Scripts\activate

    * Или используйте `poetry shell` для активации виртуального окружения (доступно только при 
    установленном плагине `poetry-plugin-shell`).*
    2. **Установите все зависимости проекта** (указанные в файле `requirements.txt`) командой:

    pip install -r requirements.txt

    Также можно установить линтеры на выбор, используя Poetry с помощью команды:

    poetry add --group lint <линтер>

    Замените <линтер> на имя нужного линтера, например `flake8` или `mypy`, и они будут указаны в pyproject.toml. 
    Если же использовать команду:

    poetry add <линтер>

    Тогда линтеры будут установлены для всего PyCharm

    3. Открыть PyCharm и установить пакеты, указанные в pyproject.toml.
